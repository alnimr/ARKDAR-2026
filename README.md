# منصة أركدار الرقمية | ARKDAR Digital Platform

تم تطوير هذه المنصة كحل "Hybrid Elite" لنشر وحفظ التراث الثقافي والفكري، مع دعم كامل لتعدد اللغات (العربية، الإنجليزية، الألمانية، الإسبانية).

## المميزات التقنية (Technical Features)

- **استقرار مطلق (Zero-Crash Architecture)**: تم بناء النظام بآليات حماية تضمن عدم تعطل الموقع حتى في حال وجود بيانات ناقصة.
- **تعدد اللغات (Multilingual)**: دعم كامل لـ 4 لغات مع تبديل سلس.
- **أداء استثنائي**: توليد 188 صفحة ثابتة لضمان أسرع وقت تحميل (Static Site Generation).
- **تصميم متميز**: واجهة مستخدم تعكس الرقي التراثي بلمسة عصرية.

## البدء (Getting Started)

```bash
npm install
npm run dev
```

## النشر (Deployment)

الموقع مهيأ للنشر التلقائي على منصة Vercel.
